Условие

Установить виртуальную машину Metasploitable, выполнить её сканирование с помощью nmap и определить доступные сетевые службы.

Найти не менее трёх уязвимостей, которым подвержены обнаруженные сетевые службы, используя базу Exploit-DB.

Ответить на вопросы:

какие сетевые службы разрешены;

192.168.56.101

Задание 2
Условие

Провести сканирование Metasploitable в режимах:

SYN;
FIN;
Xmas;
UDP.

Записать сетевой трафик с помощью Wireshark.

Ответить на вопросы:

чем отличаются режимы сканирования с точки зрения сетевого трафика;
как отвечает сервер.
Решение

Для сканирования использовалась машина с IP-адресом:

192.168.56.102

IP-адрес Metasploitable:

192.168.56.101

Для анализа пакетов использовался Wireshark.

SYN Scan

Сканирование выполнено командой:

sudo nmap -Pn -sS -p 21,22,23,80,445 192.168.56.101

При SYN-сканировании Nmap отправляет TCP-пакет с флагом SYN.

Если порт открыт, сервер отвечает:

SYN, ACK

После этого Nmap отправляет RST, не устанавливая полноценное TCP-соединение.

В результате все проверенные порты были определены как открытые.

Скриншоты







FIN Scan

Сканирование выполнено командой:

sudo nmap -Pn -sF -p 21,22,23,80,445,9999 192.168.56.101

При FIN-сканировании отправляются TCP-пакеты только с установленным флагом:

FIN

Открытые порты обычно не отвечают на такие пакеты, поэтому Nmap определяет их как:

open|filtered

Для проверки был дополнительно использован закрытый порт 9999.

На запрос к закрытому порту сервер ответил пакетом:

RST, ACK

Поэтому порт 9999/tcp был определён как closed.

Скриншоты







Xmas Scan

Сканирование выполнено командой:

sudo nmap -Pn -sX -p 21,22,23,80,445,9999 192.168.56.101

При Xmas-сканировании одновременно устанавливаются TCP-флаги:

FIN, PSH, URG

Открытые порты также обычно не отвечают и определяются как:

open|filtered

Закрытый порт 9999 ответил пакетом RST, ACK и был определён как closed.

Скриншоты







UDP Scan

Сканирование выполнено командой:

sudo nmap -Pn -sU -p 53,69,111,137,161,9999 192.168.56.101

В отличие от предыдущих режимов, UDP не использует TCP-флаги и не устанавливает соединение.

При сканировании отправляются UDP-пакеты на указанные порты.

В результате были получены следующие состояния:

53/udp    open
69/udp    open|filtered
111/udp   open
137/udp   open
161/udp   closed
9999/udp  closed

Если UDP-порт закрыт, сервер может ответить ICMP-сообщением:

Destination unreachable (Port unreachable)

Такие ответы были зафиксированы в Wireshark.

Скриншоты







Вывод

Режимы сканирования отличаются типами отправляемых пакетов и реакцией сервера.

SYN Scan — отправляется SYN. Открытый порт отвечает SYN, ACK, после чего Nmap отправляет RST.
FIN Scan — отправляется пакет с флагом FIN. Открытые порты обычно не отвечают, закрытые отвечают RST.
Xmas Scan — используются флаги FIN, PSH, URG. Открытые порты обычно не отвечают, закрытые возвращают RST.
UDP Scan — отправляются UDP-пакеты. Закрытые порты могут отвечать сообщением ICMP Destination unreachable (Port unreachable).

Таким образом, анализ трафика в Wireshark позволяет увидеть различия между режимами сканирования и определить характер ответов удалённого сервера.
